# Nomi dei moduli: italiano e inglese

La guida usa la forma **nome italiano (nome inglese)**: il nome italiano è quello della traduzione ufficiale di darktable, il nome inglese è quello che vedi se l'interfaccia è in inglese e che trovi nel manuale ufficiale e nei tutorial.

!!! note "Lingua dell'interfaccia"
    La lingua si imposta in *preferenze → generale → interfaccia → lingua*. Attenzione: non tutte le build includono la traduzione italiana (per esempio il pacchetto macOS di darktable 5.6.2 usato per preparare questa guida ne è privo): in quel caso l'interfaccia resta in inglese anche impostando l'italiano, ed è per questo che la guida riporta sempre anche il nome inglese.

Fonte: file di traduzione italiano di darktable (`po/it.po`, revisione 2025-12-22). I moduli più recenti (*color harmonizer*, *neural restore*) non hanno ancora un nome italiano.
